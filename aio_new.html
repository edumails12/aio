01 / FEATURES

under the hood

Every feature exists to either find more hits or stop bans. No filler.

/ 01

auto imap discovery

MX → SRV → Thunderbird autoconfig. No static provider tables. Catches corporate domains, custom hosts, regional ISPs that other checkers miss entirely.

/ 02

outlook graph engine

Hotmail / Outlook / Live skip IMAP and hit Microsoft Graph directly. Three-tier fallback: Graph → Substrate token → OWA. Faster, cleaner, fewer false negatives.

/ 03

inbox capture + hq scoring

Drop your keywords — PayPal, Netflix, Coinbase, banks, whatever. 71 services pre-weighted, hits sorted by HQ score. Find the gold without grepping logs.

/ 04

per-domain thread caps

Gmail = 15, Outlook = 20, Yahoo = 10, Mail.ru = 20. Built-in HostLimiter throttles per-provider so you never trip rate limits while 500 global threads stay free.

/ 05

proxy routing

HTTP / SOCKS4 / SOCKS5 — including IMAP-over-SOCKS via custom IMAP4 / IMAP4_SSL classes. Most checkers can't do this and leak your real IP on raw IMAP.

/ 06

hwid license

OTP binding via Telegram bot. One HWID = one key. Heartbeat every 6 hours, 24-hour grace on connectivity loss. Auto-updater carries the license over.
